# C++ Gradebook

A command-line gradebook application written in C++.

## Features

- Stores up to 20 students
- Stores up to 100 grades per student
- Enter grades for all students at once
- Comma-separated grade input
- Check individual student grades
- Check grades for an entire assignment
- Calculate individual student averages
- Calculate averages for all students
- Modify previously entered grades
- Input validation and warnings

Compile the program with a C++ compiler and run the resulting executable.
